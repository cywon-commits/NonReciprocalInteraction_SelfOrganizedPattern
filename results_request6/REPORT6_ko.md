## A. 큰 계의 육방상 (`hexA.py`, `anaA6.py`, 그림 `figA_hexatic.png`)

### 방법

- **계:** 정사각 격자, D = 0.4, B = 0.5D²/J, α = 0.3, β = 0.6, T = 0, 실험실 틀, 전류 ∥ x다.
- **상자:** 19×33 단위세포(스커미온 2개)를 10×5, 20×10, 30×15개 깔았다(N = 100, 400, 900; 190×165, 380×330, 570×495). 모두 거의 정사각이다.
- **진행:** 이상 격자에 10⁻² 잡음을 더해 t = 40000까지 적분했다(Heun dt = 0.2). 50 시간 단위마다 스커미온 중심을 저장했다.
- **정상상태 창:** t = 16000–40000, 200 시간 간격 121장이다.
  - 출발 결정은 u = 0.15에서 t ≈ 12000–14000, u = 0.2에서 t ≈ 7000에 녹는다. 처음에는 t ≥ 10000을 창으로 썼다가 녹기 전 구간이 섞여 ξ₆가 부풀어서 고쳤다.
  - 창을 반으로 나눈 두 값도 보고한다.
- **측정:**
  - 주기 이미지를 포함한 Delaunay 삼각분할로 배위수와 ψ₆를 구했다.
  - **ξ₆:** g₆(r) = Re⟨ψ₆ᵢψ₆ⱼ\*⟩/⟨|ψ₆|²⟩의 포락선을 0.1까지 지수 맞춤했다.
  - **ξ_T:** 쌍분포 g(r) − 1의 진동 포락선(2사이트 구간)을 0.1까지 지수 맞춤했다.
  - ξ_T를 g(r)에서 읽은 이유:
    - 처음에는 각 순간 구조인자 최대점 G로 ⟨cos G·r⟩를 쟀다. 그러면 액체에서도 양의 치우침이 생겨 ξ_T가 길게 나왔다.
    - g(r)의 마지막 반쪽 구간이 정규화 오류를 일으켜 포락선이 끊기지 않는 문제도 고쳤다.
  - **결함:** 배위수 ≠ 6인 점들을 Delaunay 결합으로 묶은 군집으로 셌다.
    - 전하 Σ(6 − z) ≠ 0: 자유 회위(|q|개)
    - 전하 0이고 2점: 자유 전위
    - 전하 0이고 4점 이상: 묶인 전위(쌍)

### 의존성 → 의미 → 가설과의 관계

- **u 의존성:** u가 커질수록 ξ₆가 줄고(2 → 0.8a₀), ξ₆/ξ_T가 2에서 1.2로 줄며, 결함 비율이 0.23에서 0.42로 는다.
  - 자유 회위 밀도는 u에 거의 무관하다(0.02).
  - 자유 전위는 u = 0.3에서 반으로 준다. 결함이 큰 군집으로 뭉치기 때문이다.
- **크기 의존성:** N = 100 → 900에서 ξ₆, ξ_T, 그 비 모두 일정하다(N = 100의 ξ₆는 상자 한계 L/2 ≈ 4.3a₀에 걸린다). 모든 길이가 1–2a₀로 상자보다 훨씬 짧으므로 64–100개 계의 결론은 크기 효과가 아니었다.
- **Ψ₆의 느린 출렁임:** 정상상태에서도 Ψ₆가 0.05–0.3 사이를 수천 시간 주기로 오간다. N = 900, u = 0.15의 앞쪽 반 창에서는 일시적으로 ξ₆ = 7a₀였다.
  - 이것은 rev 3에서 기술한 "결함이 움직여 질서를 키우는 과정과 질서에 비례하는 펌핑의 경쟁" 그림과 맞는다.
  - 그러나 시간 평균으로는 육방 질서가 남지 않는다.
- **판정:** 큰 계에서 ξ₆ ≫ ξ_T인 육방상은 **나타나지 않는다.** 흐르는 상태는 결합 방향 상관이 병진 상관보다 1.5–2배 긴 액체다. 그 차이는 u가 클수록 사라진다.

## C. 줄무늬: 유한 상자 문턱과 문턱 위 종착 상태

### 방법 (공통)

- **줄무늬 모형:** 대각선 줄무늬(q ∥ (1, 1)), D = √2 J tan(2π/P)로 피치를 정했다. B = 0, α = 0.3, β = 0.6, 줄무늬와 함께 움직이는 틀(w₁ = u_eff(cos, sin)(45° + φ), w₂ = 0)이다(`code/stripe/conv.py`).
- **기울어진 상자(`nbrllg.py`):** 사이트를 n = i + j(줄무늬를 가로질러)와 m = j(줄무늬를 따라)로 쓰고, 이웃표로 LLG를 적분한다.
  - **n 방향 경계:** 나선 경계다. (n + N_n, m) = (n, m − N_n/2)이고, 이는 q 방향 격자 이동 (N_n/2, N_n/2)에 해당한다.
    - 단순 주기 경계 (n + N_n, m) = (n, m)는 격자 이동 (N_n, 0)이다.
    - 그 경우 가장 낮은 모드가 굽힘이 아니라 k_q = k_e인 압축 섞인 모드가 되어, 첫 시험에서 문턱을 잘못 쟀다.
  - **m 방향:** 한 걸음이 격자 벡터 (−1, 1)이므로 줄무늬 길이는 L = √2 N_m이다.
  - **검증:** 1D 정지 상태에서 잔차가 2×10⁻¹⁵로 1D 모형과 같다.

### C1. 유한 상자 문턱 (`stripeC.py`, `anaC1.py`, `c1fix.py`, 그림 `figC1_thresholds.png`)

**방법.**

- **Bloch:** 수렴 1D 정지 상태(잔차 < 10⁻¹²)의 Bloch 야코비안을 k = 2π/L ∥ ê에서 풀고, u_eff에 대해 이분법을 썼다.
- **동역학:** 줄무늬 한 주기 폭(N_n = P)의 상자에 굽힘 n → n + 0.005 cos(2πm/N_m)를 심었다. 줄별 변위 δ(m)의 k₁ 성분 F₁(t)을 기록하고, 두 지수의 합으로 Prony 맞춤해 두 가지 λ± = Γ ± iω를 얻었다.
  - u = 0.9, 1.0, 1.1 × Bloch 값에서 max Γ의 영점을 보간했다.
  - 성장률이 Bloch 고유값과 10⁻⁶ 수준까지 같다. 예: P = 30, L = 64에서 동역학 −3.40, +0.07, +3.46 (×10⁻⁴), Bloch −3.4, +0.1, +3.5.

  - 동역학으로 측정 범위를 넓혀 실제 굽힘 문턱을 쟀다.

**의존성 → 의미 → 가설과의 관계.**

- **L 의존성:**
  - u\*(L) − u\*(∞)는 대략 L⁻²로 준다.
  - P = 60은 c₀가 작아(0.0165) 상자 효과가 크다. L = 64 → 512에서 문턱이 2.3배 바뀐다. P = 30에서는 1.17배다.
  - 의뢰서가 예상한 "P = 60에서 상자 효과가 보인다"가 확인됐다.
- **해석식과의 비교:**
  - P = 30에서는 모든 L, φ에서 ±2% 안이다.
  - P = 60에서는 L ≥ 128일 때 ±3.5% 안이다.
  - P = 60, L = 64에서는 해석식이 8–31% 높다. k₁ = 0.099가 줄무늬 파수 2π/(60/√2) = 0.148과 비슷해서, ω² = c₀²k² + c_b²k⁴ 전개가 깨지기 때문이다.
- **판정:** L ≳ 2P에서 예측식이 **성립**한다. 짧은 상자에서는 굽힘 분산의 고차 항이 문턱을 낮춘다.

### C2. 문턱 위 종착 상태 (`stripeC2.py`, `anaC2.py`, `growthC2.py`, 그림 `figC2_growth_endstates.png`)

## D. 비상반 DMI δD의 장형 채널 (`dD.py`, `anaD.py`, 그림 `figD_deltaD.png`)

### 모형

결합형(교환에 짝, n(ê) = n) DL 채널을 다음 토크로 넣었다.

  T_i = −δD Σ_{ê = x, y} S_i × [S_i × (n × (S_{i+ê} + S_{i−ê}))]

S_{i+ê} + S_{i−ê} = 2S_i + ∂_ê²S로 전개하면 두 항이 나온다.

- **1차 항:** −2δD S×n(축마다), 즉 유효 Zeeman 장 4δD n이다(장형 토크, 축성, T-홀).
- **나머지:** 2차 비상반 강성 −δD Σ_ê S×[S×(n × ∂_ê²S)]다.

비교한 세 형태는 다음과 같다.

- `local`: 1차 항만
- `stiff`: 2차 항만
- `full`: 결합 전체

계산 조건은 다음과 같다.

- **격자:** SkX 19×33(그리고 76×33), B = 0.5D²/J, α = 0.3, 전류 없음
- **정지 상태:** 움직이는 틀에서 표류 V를 풀었다(`code/b1/sot.py` 방식, 잔차 < 2×10⁻¹³).
- **포논 쌍:** k = ±(2π/380, 2π/95, 2π/38) ∥ x, y의 Bloch 고유값이다.
  - 76×33 상자의 k = 2π/76 ∥ x는 Γ점과 같아 제외했다.
  - k = 2π/38 ∥ x는 영역 경계라 갈림이 대칭으로 0이다.

### 결과

- **정적 변형:**
  - local: 면내 자화 ⟨S·n⟩ ≈ 19δD(유효장에 대한 감수율)이고, 타원율이 1.014에서 1.031로 변한다(δD = 0.008).
  - stiff: ⟨S·n⟩ ≈ −0.32δD이고, 모양 변화가 없다(타원율 1.0135 그대로).

### 의존성 → 의미 → 가설과의 관계

- **1차(국소) 장형 채널:**
  - 격자를 움직이지 않는다(V ~ 10⁻¹⁷).
  - 감쇠율 변화는 δD = 0.008에서도 두 가지가 함께 6% 줄 뿐이고, 갈림은 무시할 만하다.
  - 가설 "장형 채널은 펌핑하지 않는다"는 **이 항에 대해 맞다.** B1의 "< 0.05%"는 δD = 0.002에서의 갈림 값과 일관된다.
- **2차 비상반 강성(∂_ê²S):**
  - **표류:** 격자를 끌고 간다. V = −(0.239 ẑ×n + 0.104 n)δD로, n과 함께 도는 축성 벡터처럼 변한다(n = ŷ, x̂ 비교). 표류는 주로 ẑ×n 방향이다.
  - **±ω 비대칭:** 포논 쌍의 두 가지(±ω)를 반대로 벌린다. 한 가지는 덜 감쇠되고 다른 가지는 더 감쇠된다.
    - 갈림 기울기는 k에 대략 비례한다(k ∥ x에서 2.1×10⁻³ → 7.8×10⁻³, k 4배에 3.7배).
    - 감쇠율은 k²에 비례한다(7.2×10⁻⁵ → 1.1×10⁻³).
    - 그래서 문턱 δD\*(k)도 k에 비례한다(0.034 → 0.14). 무한계에서 문턱이 0인 도플러형 펌핑이다.
  - **"이류 없는 비상반 분산" 가설:** 움직이는 틀에서 순수 표류의 도플러는 상쇄된다(αw₁ + w₂ = 0). 따라서 이 갈림은 표류에 의한 이류가 아니다. 2차 강성 토크가 포논에 직접 작용한 결과다. 가설이 말한 "이류 없는 ±k(±ω) 비대칭 실수부"가 **확인**된다. 이것은 문턱을 갖는 펌핑으로 이어진다.
  - 이 항이 만드는 정적 변형은 작다(면내 자화 −0.32δD, 모양 불변). 동역학 효과(표류와 펌핑)가 주된 결과다.
- **n = ẑ:** 유효장이 B를 4δD만큼 키우는 효과뿐이다. 갈림과 표류가 없고, δD ≈ 0.018(B_eff ≈ 0.15 ≈ 0.95D²)에서 두 가지가 함께 연화된다. SkX 안정 한계에 다가가는 정적 불안정이다.
