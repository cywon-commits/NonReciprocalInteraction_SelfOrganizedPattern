## 확인된 것과 고칠 것

1. 자기 점군은 초안 III절 표와 모두 일치한다.
2. SkX의 잔여군은 pm′가 아니라 cm′(Cm′, BNS 8.34)다. 삼각 격자에서 거울 하나만 남으면 단위세포가 중심 직사각형이 되기 때문이다. Bloch SkX도 c2′(C2′, 5.15)다.
3. 비상징 성분이 선택 규칙을 지킨다.
   - Néel 사이클로이드(u ∥ q)에서 M_z를 금지하는 원소는 a-활주면 m_y t_{λ/2}와 2_z′t_{λ/2}다. 둘 다 반주기 반병진 T t_{λ/2}와 묶여서 생긴다.
   - 반주기 병진은 주기 N이 짝수일 때만 격자 연산이다. N이 홀수인 공약 고정 상태에서는 잔여군이 Pm′(6.20)로 내려가 M_z가 허용된다(격자 고정이 만드는 2차 효과).
   - 비공약 무늬에서는 초공간 내부 병진 (1′|0,0,0,½)이 항상 있으므로 짝수 N 결과가 맞다. 정확한 분류는 자기 초공간군이고, 위 BNS는 짝수 주기 근사의 이름이다.
4. 공간군 번호는 호스트 격자에 의존한다. 예를 들어 Bloch 나선은 정방 호스트(c = b)에서 P_c4₃22(95.140), 편향 시 P4₃2′2′(95.138)이 된다. 논문에는 자기 점군과 비상징 생성원(활주, 나선축, 반병진)을 쓰고, BNS는 "최소 호스트(직방정·육방) 근사"로 표에 덧붙이는 것을 권한다.
5. 박막(Néel)은 모든 연산이 z를 보존하므로, 자기 층군 기호가 위 극성 공간군과 같은 HM 기호를 갖는다. Litvin 층군 번호는 따로 조회하지 않았다.
