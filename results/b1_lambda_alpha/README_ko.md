## 결론

1. α → 0 극한에서 λ = κ_P(1% 이내)이다. 이것은 LL형 식에서 바로 나온다. Gilbert 식을 LL 꼴로 바꾸면 소산 자리의 벡터는 W₂ = w₂ + αw₁ = (β − α)u로, Hall 운동 V와 무관하게 정확히 u 방향이다.
2. α 의존은 순수한 α²이다(α ≤ 0.3에서 ΔuA/u₀ ÷ α² = 0.11 ± 0.01(B = 0.5), 0.36 ± 0.02(B = 0.7)).
3. 측정한 α² 계수는 Gilbert형 Hall 가중 평균 추정의 0.5배(B = 0.5), 0.6배(B = 0.7)다. 모든 α에서 이 비가 일정하다.
4. 분해:
   - 포논 쌍 안(uG): Hall 가중은 거의 상쇄된다(±0.3% 이내, 두 자기장에서 부호가 반대).
   - 나머지(uA − uG)는 구동 바탕에서 온다. B = 0.7, α = 0.3에서 쌍 안의 바탕 변형 +4.5%, 내부 모드와의 섞임 −0.5%다(`lc07b.log`).
5. α = 0.6은 αP ≈ 1(임계 감쇠 근처)이라 섭동 분해가 무너진다(`lc07a.log`). 정량 주장은 α ≤ 0.3으로 한정한다.
6. 수렴: B = 0.7에서 정상 상태 잔차가 3.5×10⁻⁶에서 멈추지만, 성장률은 반복에 대해 10⁻¹¹까지 안정적이다(`cc07*.log`).

`lb05.log`, `lb07.log`(du = 0.002 선형 분해)는 바탕 기울기 s_S가 잡음 수준(du·s_S ~ 5×10⁻⁸)이라 참고용이다.
