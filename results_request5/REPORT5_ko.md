## (A) 균일 변형 세포의 연화 가지

### 방법

## (B) 매개변수 없는 γ_c(L) 예측

### 방법 (`weylB.py`, `weylB_shift.py`)

1. **국소 분산.**
   - 과제 A의 극좌표 격자에서 Q = λ/k²를 (log k, θ) 쌍선형으로 보간한다.
   - 각 ε 선에서는 Q를 여유 m의 함수로 둔다.
   - ε는 선 사이 선형 보간이고, [−0.105, 0]에서 자른다.
2. **두 모형.**
   - **주 모형:** 모든 계산 상태를 지나는 조각 선형(`MODEL_FORM=pw`). 독립 자료인 k_x 단면(k_y = 0.127, 0.19)을 10–20%로 재현한다.
   - **비교 모형:** |m| < 0.03 상태로 맞춘 선형 Q = A m + B(`lin`). 같은 단면을 최대 3배까지 틀린다.
3. **필요했던 보정 세 가지.** 모두 계산 자료의 범위를 넘는 외삽을 막는 것이다. 맞춤 매개변수는 아니다.
   - **(i) 바닥:** 연화 가지는 두 음향 편광 중 큰 쪽이다. 다른 편광은 m에 무관하게 Q ≈ −0.23에 있으므로, Q ≥ (θ에 대한 최소)로 바닥을 둔다.
   - **(ii) 여유 하한:** m < −0.015(계산된 최소 여유)에서는 Q를 그 값에 고정한다.
     - 변형파는 m이 −0.57까지 내려간다.
     - 선형 외삽을 그대로 쓰면 큰 k에서 Q > 0인 가짜 불안정이 생겨, 연산자가 모든 상태에서 불안정했다.
     - 계산된 모든 m < 0 상태에서 Q는 어디서나 음수다.
   - **(iii) k 범위:** |k| ≤ 0.2 격자로는 부족했다. 작은 상자의 문턱 모드는 m ≈ 0.07–0.12에서 k ≈ 0.2에 있다. 그래서 0.40까지 늘렸다(연산자 |k_x|, k_y ≤ 0.35).
4. **연산자.**
   - 각 k_y = 2πn/L_y(L_y = 0.434L_x)에서 평면파 기저 k_x = 2πj/L_x로 Weyl 양자화한다: ⟨k|Λ|k′⟩ = (1/L)∫e^{−i(k−k′)x}λ((k+k′)/2, k_y; m(x), ε(x))dx.
   - 비교용 대칭화는 ½[λ̃(k; q) + λ̃(k′; q)]이고, λ̃는 λ(k, k_y; x)의 Fourier 성분이다.
   - k = 0(균일 병진, Goldstone)은 n = 0 기저에서 뺐다.
5. **문턱.**
   - 모든 상태에서 Λ₀ = max_n Λ₀(n)을 구한다.
   - 측정된 m(x)를 통째로 Δ만큼 내렸을 때(또는 올렸을 때) Λ₀ = 0이 되는 Δ\*를 이분법으로 찾는다.
   - γ_c^pred = γ_wave − Δ\*/(dm_max/dγ_wave)이고, 기울기 1.30–1.36은 각 크기의 상태열에서 잰다.
   - 상태열 내 예측의 흩어짐은 ±0.001 이하다.
6. **입력 상태:**
   - m(x), ε(x): `margin5.py`(`margin.py`와 같은 1–3차 y 균일 조화, 같은 γ_s(ε) 지도)
   - 의뢰 4 `C/states/{8x2, 12x3, 16x4}`, 의뢰 5 `C1/states/24x6`, 의뢰 3 `A32/chain`(32×8)

### 가설과의 일치/불일치

- **§0.2(조화 가둠, 유한 k 띠): 불일치.** 균일 세포에 띠가 없다. 그런데도 연산자는 임계 모드를 유한 k(≈ 0.2)에 만든다. 이것은 여유 우물의 최대 근처에서 국소 분산의 k\*(m)가 커지기 때문이다. 배경이 새 띠를 만든 것은 아니다.
- **§0.3(장파장형, 가우스 근사): 부분 일치.**
  - 맞는 것: 국소 분산의 꼴, 그리고 문턱이 우물 크기와 곡률로 정해진다는 구조.
  - 맞지 않는 것: 스케일 불변성 m_max·L = 상수. 연산자의 m_crit·L은 14.8 → 32.8로 L과 함께 자란다(≈ L^0.57).
  - 이유: 문턱 모드가 k⁴, k⁶ 항이 지배하는 k ≈ 0.2에 있고, 가우스 근사(k → 0 전개)의 범위 밖이다.
  - 측정된 m_max·L(18.4 → 27.3)도 L^0.3 정도로 자란다. 예측과 측정 모두 "m_max·L = 상수"에서 벗어난다는 점은 같다.
- **ℓ_K = 6.4:** 맞춤 없이 재현되지 않는다. 그러나 ℓ_K라는 하나의 상수가 없어도, 측정 분산과 측정 프로파일만으로 γ_c(L)의 대부분을 재현한다.
- **결론:** 1/L 보정의 주원인은 "여유 우물 + 국소 분산"이 맞다. 다만 조화·장파장 근사의 상수 하나로 요약되지 않는다. 작은 상자(L ≤ 304)에는 정적 국소 근사를 넘는 기여가 0.005–0.016 남는다. 8×2에서는 이류가 그 후보다.

### C0: 의뢰 4 Floquet 벡터의 재분석 (`c0.py`)

**방법.**

- 각 skyrmion 핵(m_z < 0)에서 δS를 ∇S로 투영해 강체 변위 d_j를 얻는다.
- d_j를 이상 격자 위치 X_j에 둔다(`regist.topo`).
- 변위장 Fourier P(K)를 삼각 격자의 첫 Brillouin 영역으로 줄인다.
  - 이 축소는 처음에 ±3, 다음에 ±12 역격자 벡터로 했는데 상자 모서리(|k_x| ≈ π)에서 부족했다. 최종은 ±20이다.
  - 축소가 덜 되면 등가인 점들이 동률로 남아, 예컨대 8×2의 운반 파수가 (0, 0.286)으로 잘못 읽힌다. 올바른 값은 (0, 0.095)다.

**의미.**

- 문턱 모드는 x로 국소화되고 y로 파동치는 변위 패턴이다. 행마다 x 변위의 부호가 바뀌는 "행 미끄러짐"이다.
- 폭은 크기에 무관한 약 20사이트다.
- **정정:** 의뢰 4 C3이 보고한 운반 파수 "|k| ≈ 0.14–0.16, θ ≈ 113°"는 스핀장 Fourier와 불충분한 영역 축소에서 온 접힘 착오였다. 이 보고서의 값으로 바꾼다. 앞서 이 작업 중에 말한 "모든 크기에서 M점(0, 2π/33)"도 정정한다. M점 k_y = 0.19는 12×3, 16×4에서만 주된 성분이다.

**가설과의 일치/불일치.**

- σ/√L: 12×3, 16×4는 1.24, 1.14로 §0.2의 1.24 쪽에 가깝다. 그러나 σ가 L에 무관하므로 σ/√L은 L과 함께 줄어든다(그림 5).
- σ·k\* = √2(§0.3): 불일치.
- 운반 파수 ∝ L^(−1/2): 불일치.
- 과제 B 예측과의 비교: 같은 k_y(0.19)와 같은 중심(+8 … +12)을 준다. 폭은 절반이고(8–14), k_x = 0.06–0.08로 Floquet(k_x ≈ 0)과 다르다. 의뢰서의 "운반 파수가 L에 무관" 경우에 해당한다. 유한 k 구조는 배경이 만드는 접힘 띠가 아니라, 국소 분산 k\*(m)가 우물 꼭대기의 큰 여유(m ≈ 0.1)에서 0.2에 이르는 것으로 이해된다.
