## 2. 측정 정의(과제 0)

- **연쇄**: `run3.py`. 의뢰 2의 1.06 u_c 평형 상태에 10⁻³ 잡음(시드별로 다름)을 넣고 1.06, 1.065, 1.07, 1.0725, 1.075, 1.0775, 1.08, 1.0825, 1.085, 1.09, 1.095, 1.10 u_c로 올린다. 매 단계의 머무는 시간은 8×2 10⁵, 12×3 1.5×10⁵, 16×4 2.5×10⁵, 24×6과 32×8 4×10⁵이다.
- **평형 판정**: 마지막 두 사분기의 γ_max 평균 차이가 1% 미만이어야 한다. 아니면 최대 2배까지 연장한다. 온전한 단계 147개 중 미평형은 7개였다. 4×1 임계 이하 단계 5개는 무늬가 없어 판정이 의미 없다. 나머지 2개는 α = 0.15 12×3의 첫 단계(1.06)로, 4×1에서 키운 출발 상태가 계속 이완 중이었다. 과제 0과 A에서는 모든 온전한 단계가 평형이다.
- **γ_max**: Delaunay 삼각형별 ∂x u_y의 최댓값(의뢰 2와 같음).
- **γ̄_max**: 반경 R = 37.5 사이트(연화 모드 파장 4a의 절반) 원판 평균의 최댓값. 원판 중심은 스커미온 위치에 둔다.
- **γ_wave**: ∂x u_y를 x 방향 1–3차 Fourier 성분으로 맞춘 1D 프로파일의 최댓값.
- **t_slip**: Burgers 결함이나 Bragg 지수 변화가 처음 생긴 기록. 그 뒤 2×10⁴ 시간 단위 동안 계속 깨져 있으면 영구, 회복되면 일시적이다.
- **γ***: t_slip 직전 n = 1, 3, 5개 기록의 평균. 표에는 n = 5를 쓴다.
- **오차**: 시드 간 표준오차와 "단계 오차"를 제곱합한 값이다. 단계 오차는 미끄러진 단계와 바로 아래 단계의 포화 변형 차이의 절반이다. 미끄러짐은 이 두 값 사이 어딘가에서 일어나므로 이 오차가 들어가야 한다. 시드 간 오차만 쓰면 0.0001 수준까지 작아져 맞춤의 χ²가 수백이 된다.

### 2.2 γ*가 머무는 시간에 의존한다는 점

머무는 시간을 두 배(2×10⁵)로 늘린 8×2 연쇄는 한 단계 일찍(1.085) 미끄러졌고, γ*_max는 0.385에서 0.372로 바뀌었다. 연쇄의 γ*는 재료 상수가 아니라 **동역학 문턱에 머무는 시간 의존 여분을 더한 값**이다(§4.3). 그래서 크기 보정 지수는 프로토콜에 무관한 문턱 γ_c(L)로도 같이 쟀다.

**γ_c(L)의 정의**: 각 단계에서 연화 모드 진폭의 성장률 Γ를 잰다(§4.3). Γ ≈ 0(잡음 수준, Γ < 2×10⁻⁵, 진폭이 잡음 바닥 10⁻¹⁰에 머묾)인 마지막 단계와 Γ > 0으로 자라기 시작한 첫 단계 사이에서, γ_wave로 표시한 경계가 γ_c다. 두 단계의 γ_wave가 구간이 되고, 성장 단계가 둘이면 Γ(γ)의 직선 외삽으로 추정값을 정한다. 머무는 시간 2배 연쇄의 γ_c는 0.362로 기본 연쇄와 같다(0.3595–0.364). 즉 γ_c는 머무는 시간에 무관하다.

| 크기 | γ_c 추정 | 구간 |
|---|---|---|
| 8×2 | 0.362 | 0.359–0.364 |
| 12×3 | 0.347 | 0.344–0.349 |
| 16×4 | 0.333 | 0.329–0.334 |
| 24×6 | 0.316 | 0.314–0.318 |
| 32×8 | 0.305 | 0.301–0.310 |

**의존성**
- 세 정의(γ_c, γ*_max, γ*_wave) 모두 p = 1/2이 가장 잘 맞고, p를 키울수록 χ²가 단조롭게 커진다.
- L⁻¹ 그림에서 점들이 아래로 오목하다. 크기가 클수록 기울기가 커지므로 p < 1을 뜻한다.
- 32×8의 측정값 γ*_max = 0.314 ± 0.005는 의뢰서 예측(p = 1/2: 0.318, 1: 0.323, 4/3: 0.327, 2: 0.332)보다 모두 낮다. p = 1/2과만 1σ 안에서 맞는다.
- γ̄*는 12×3 이상에서 L에 대해 거의 직선으로 내려가며(0.320 → 0.304), 24×6과 32×8 사이에서 γ_s(0) = 0.308을 지난다.

**의미**
- p = 1/2이면 γ_c(∞) ≈ 0.25 < γ_s(0)이다. 큰 계에서는 정적 안정 경계보다 낮은 변형에서 미끄러진다는 뜻이다.
- 크기 범위가 4배(152–608)뿐이어서 γ∞의 계통 불확실성은 크다. 그래도 "γ_s(0)로 수렴하며 p = 4/3"인 가설 조합은 맞춤의 질(χ² 18.6–25.8, 자유도 3)로 볼 때 기각 쪽이다.
- 48×12(L_x = 912)에서 γ_c의 예측은 p = 1/2이면 0.298, p = 1이면 0.306, p = 4/3이면 0.311이다. 48×12의 γ_c가 0.30 이하로 나오면 γ_s(0) 아래로 내려감이 확정된다. 이것이 GPU가 생기면 할 가장 결정적인 다음 계산이다.

**가설과의 일치/불일치**: **불일치**. 의뢰서 §2의 대안(p = 1/2, γ*(∞) ≈ 0.25)과 일치한다.

## 4. (B) 머무는 시간 논증의 고리별 검사

방법은 `anaB.py`(미끄러짐 직전 버퍼)와 `anaG.py`(모든 단계의 궤적, 500 시간 단위 간격)다. 그림은 `fig2_growth.png`다.

### 4.1 고리 1: 변형파의 상대 속도 v ∝ 1/L — 성립

- 거칠게 만든 γ_wave 프로파일의 최댓값 위치를 격자 좌표에서 추적했다.
- α = 0.3의 버퍼 19개에서 v·L_x = 12.22 ± 0.05이다(8×2부터 32×8까지, 12.15–12.27; 1.095의 한 버퍼만 12.40).
- 방향은 모든 경우 격자 좌표 +x(스핀 전달 항 w₁ = (−u, 0)과 같은 축)다. 전류를 바꾸지 않았으므로 부호 비교는 하지 않았다(과제 D).
- α에 따라 조금 바뀐다: v·L은 α = 0.15에서 11.65, α = 0.6에서 13.9–14.1이다.

### 4.2 고리 2: 임계 영역 폭 w ∝ L√Δ — 성립

- w는 γ_wave(x) > γ_s(0)인 x 영역의 폭이고, Δ = γ_wave,peak − γ_s(0)이다. 둘 다 미끄러짐 직전 10기록의 평균이다.
- w/(L√Δ)는 L = 152–608, Δ = 0.0035–0.08(20배 범위)에서 0.72–0.87(평균 0.78)이다. 10% 안에서 일정하다.
- α = 0.6에서는 0.64–0.72로 조금 낮다.

### 4.3 고리 3: 연화 모드 성장률 Γ(Δ) — 불성립

연화 모드 진폭 a의 측정은 다음과 같다(의뢰서의 방법 (a)).
1. 스커미온 변위장에서 y 방향으로 균일한 변형파(x 방향 1–6차)를 뺀다.
2. 남은 변위를 0.06 < |k| < 0.11, 0.045 < |k_y| < 0.1 띠의 평면파(정적 연화 모드 k = (−0.043, 0.071), 파장 4a)에 투영한다.
3. 그 최댓값을 a로 쓴다.

창은 두 가지로 썼다. 하나는 격자 전체이고(Γ), 다른 하나는 격자에 고정된 미끄러짐 지점 창과 파와 함께 움직이는 창이다(버퍼).

**의존성**
1. **문턱 아래에서는 Γ = 0이다.**
   - γ_c(L) 아래의 모든 단계에서 진폭은 잡음 바닥(약 10⁻¹⁰)에 머물고 Γ < 2×10⁻⁵이다(대부분 |Γ| < 10⁻⁵, 일부는 −4×10⁻⁵까지 음수).
   - 국소 최대 변형이 γ_s(0)를 크게 넘어도 그렇다. 예를 들어 8×2 1.0825 u_c에서 γ_wave = 0.359, Δ = γ − γ_s = 0.051인데 Γ = 0이다.
   - 가설의 Γ = Γ′(γ − γ_s)를 넣으면 Γ ≈ 1×10⁻³이 되어야 하고, 10⁵ 시간 단위 동안 e^100배 자랐어야 한다.
2. **γ_c를 넘으면 Γ가 가파르게 켜진다.**
   - 첫 성장 단계의 Γ는 3×10⁻⁵–1.3×10⁻⁴(α = 0.3)다.
   - 8×2에서는 성장 단계가 둘이라 기울기를 잴 수 있다: dΓ/dγ ≈ 0.037. 정적 Γ′(α = 0.3) = 0.020과 같은 크기다.
   - 즉 "γ − γ_c(L)에 비례하는 성장"이지, "γ − γ_s에 비례"가 아니다(그림 2 오른쪽).
3. **성장은 국소적이지 않다.**
   - 격자 전체를 24개 창으로 나누면, 진폭의 중앙값도 최댓값과 함께 같은 비율로 자란다.
   - 최댓값은 격자가 아니라 변형파와 함께 움직인다.
4. **미끄러짐 직전(비선형) 구간의 Γ**는 1–2×10⁻³로 크기와 Δ(20배 범위)에 무관하다. 이 구간은 선형 성장률이 아니라 핵생성 자체의 시간 척도다.

**의미**: 미끄러짐의 원인은 국소 변형이 γ_s를 넘는 영역에서의 연화 모드 증폭이 아니다. 구동된 변형파 상태 전체의 선형 불안정이 γ_c(L)에서 켜지는 것이다. 이 불안정 모드는 국소 정적 연화 모드와 파장·편광이 같은 띠에 있지만, 문턱은 국소 정적 기준이 아니라 변형파 전체의 구조(L에 따른 w, v 등)가 정한다.

### 4.4 고리 4: 누적 성장 ∫Γdt — 불성립

- **임계 영역을 지나는 동안의 누적 성장**: 격자에 고정된 미끄러짐 지점 창에서 Δ_loc > 0인 동안 ln a의 증가량은 0–2.7로 흩어져 있다. 크기와 체계적 관계가 없다.
  - 한 번 지나가는 시간 t_res = w/v는 8×2 약 390, 32×8 약 1,500이다.
  - 선형 성장률(<10⁻⁴)을 곱하면 지나가는 한 번에 0.04–0.15 e-배에 불과하다.
- **실제로 미끄러짐을 일으킨 누적 성장**: 진폭이 잡음 바닥(10⁻¹⁰)에서 O(1)까지 자라는 ln 21–23이다. 이는 파가 격자를 수십 번 도는 시간(주기 L²/12.2: 8×2 약 1,900, 32×8 약 30,000)에 걸쳐 쌓인다.
  - 이 값은 크기에 무관한 상수지만, 가설의 "머무는 동안 수 e-배"가 아니라 잡음 수준이 정하는 상수다.
  - 그래서 연쇄의 γ*는 머무는 시간과 잡음 크기에 로그로 의존한다(§2.2).
- 미끄러지지 않은 바로 아래 단계의 누적 성장은 0이다(진폭이 바닥에 머묾).

### 4.5 고리 조합과 p

- 고리 1·2는 성립하지만, 3·4가 깨지므로 Δ^(3/2)L² = 상수(p = 4/3)는 나오지 않는다.
- 측정된 γ_c(L)는 p ≈ 1/2에 맞는다(§3). 고리별 지수를 조합해 p를 예측할 수 없다는 것 자체가 결과다.
- 측정된 사실을 그대로 쓰면 "γ_c(L) − γ∞ ∝ L^(−1/2)"이다.
- 남는 물음: 구동된 변형파의 전역 모드 문턱이 왜 L^(−1/2)로 내려가는가. 후보 하나는 다음과 같다. 변형파의 폭 w ∝ L√Δ가 커질수록 모드가 넓은 영역에 퍼질 수 있어 가둠 비용이 줄어든다. 이 경우 문턱이 정적 균일 전단의 γ_s(0)가 아니라 다른 극한으로 갈 수 있다. 이 해석은 검증하지 않았다.

### 5.3 예측과 비교

- **정적 Γ′(α)**: 균일 전단 γ = 6/19의 Bloch 고유값에서 구했다(`gprime.json`). Γ′ = 0.036(α = 0.15), 0.020(α = 0.3), 0.0103(α = 0.6)이다. α·Γ′ ≈ 0.006으로 일정하므로 **Γ′ ∝ 1/α**다. 의뢰서의 추정 Γ′ ∝ α/(1 + α²)와 방향이 반대다(그림 3 가운데).
- **γ_s(0)의 α 무관성**: 같은 계산에서 s = 5(γ = 0.263)는 세 α 모두 안정이고(최대 고유값 약 0, Goldstone), s = 6(0.316)은 세 α 모두 불안정이다. 정적 Hessian은 α를 포함하지 않으므로 γ_s(0) = 0.308은 α에 무관하다.
- **가설의 예측**: Δ* ∝ (Γ′·t_res)^(−2/3), t_res = w/v이고, v·L은 측정값을 쓴다. α = 0.3의 Δ* = γ*_max − γ_s(12×3 0.061, 16×4 0.036)를 기준으로 하면 다음과 같다.

| α | 예측 Δ*(α)/Δ*(0.3) | 12×3 예측 γ* / 측정 γ* | 16×4 예측 γ* / 측정 γ* | 측정 Δ*/Δ*(0.3) (12×3, 16×4) |
|---|---|---|---|---|
| 0.15 | 0.66 | 0.348 / 0.364 ± 0.003 | 0.332 / 0.338 ± 0.003 | 0.92, 0.83 |
| 0.6 | 1.69 | 0.411 / 0.371 ± 0.007 | 0.369 / 0.348 ± 0.003 | 1.04, 1.10 |

  Δ* ∝ Γ′^(−x)로 실효 지수를 구하면 x = 0.06–0.32이다. 가설은 x = 2/3을 예측한다.

**의존성**
- 문턱 γ_c는 α에 대해 구간 안에서 일정하다. 12×3은 0.342, 0.347, 0.347이고, 16×4는 0.327, 0.333, 0.329다.
- 연쇄의 γ*_max는 α와 함께 조금 커진다. 12×3은 0.364 → 0.369 → 0.371이고, 16×4는 0.338 → 0.344 → 0.348이다. 이 차이(0.005–0.01)는 문턱을 넘은 뒤 성장률이 달라져서 생기는 '머무는 시간 여분'의 차이로 볼 수 있다(§2.2).

**의미**: 미끄러짐 문턱은 감쇠(성장률의 크기)가 아니라 변형파의 구조(정적·보존적 성질)가 정한다. 감쇠는 문턱을 넘은 뒤 얼마나 빨리 자라는지, 그래서 연쇄의 γ*에 붙는 작은 여분에만 영향을 준다. 이는 §4의 "문턱 = 전역 불안정의 시작점"이라는 그림과 맞는다.

**가설과의 일치/불일치**: **불일치**. 의뢰서의 최소 조건("Δ*가 α에 따라 단조롭게 변하고 γ_s(0)는 불변")은 연쇄의 γ*에 대해서는 약하게 성립한다. 하지만 변화의 크기는 가설 예측의 일부(실효 지수 0.06–0.32, 예측 2/3)이고, 프로토콜에 무관한 문턱 γ_c는 α에 무관하다. 크기 보정을 성장률과 머무는 시간의 곱으로 설명하는 가설은 지지되지 않는다.

## 7. 계산 중 발견해 수정한 문제

- **α = 0.15에서 dt = 0.2의 Heun 적분이 불안정**: u = 0.033에서도 수백 시간 단위 안에 격자가 붕괴했다. α = 0.15만 dt = 0.1을 썼다(dt = 0.05와 10⁻⁶까지 일치). α = 0.3과 0.6은 dt = 0.2가 안정하다.
- **의뢰 2의 24×6 `S_seed_r1.06.npy`는 이미 미끄러진 상태**였다(Bragg 지수 (2, −4)). 24×6은 의뢰 2 연쇄의 1.06 상태 `S_chain_r1.06.npy`에서 시작했다.
- **α = 0.15 16×4의 축척 시드가 넘침**: 4×1에서 키운 출발 상태가 1.06에서 곧바로 미끄러졌다(γ = 0.36). α = 0.3 16×4의 1.06 평형 상태에서 다시 시작했다.
- **연화 모드 띠 투영의 첫 구현 오류**: 매끈한 성분으로 |n| ≤ 1을 빼서 8×2의 띠 모드가 지워졌다. 같은 y 성분(n = 0)만 빼도록 고쳤다. 고친 뒤의 결과만 보고했다.
